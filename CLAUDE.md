# CLAUDE.md

This file gives Claude Code guidance for working in this repository.

## What this repo is

`victoryborsa/victoryborsa` is a GitHub **profile repository**: its `README.md` is shown on
https://github.com/victoryborsa. There is no application code, build, or test suite.

## Working here

- Content changes go in `README.md`, written in GitHub-flavored Markdown.
- GitHub renders a limited Markdown/HTML subset on profiles: no JavaScript or custom CSS.
  Use Markdown, plain HTML tags (`<p align="center">`, `<img>`, `<details>`), and image URLs
  (badges from shields.io, stats cards, etc.).
- The HTML comment at the bottom of `README.md` is GitHub's template note; it is invisible on
  the profile and can be removed.
- Preview changes by checking how they render on GitHub before calling a change done.
