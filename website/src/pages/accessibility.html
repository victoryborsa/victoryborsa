Accessibility Statement

Last updated August 23, 2026

PGH Shine Pro Cleaning Services is committed to ensuring our website is accessible to all users, including people with disabilities. We continually work to improve the accessibility of our site and welcome your feedback.

Our commitment

We believe everyone deserves equal access to information and services online. Shine Pro strives to provide a website that is perceivable, operable, understandable, and robust — the four principles of the Web Content Accessibility Guidelines (WCAG) 2.1.

We target conformance with WCAG 2.1 Level AA. While we work toward full conformance, we recognize that accessibility is an ongoing effort and we are committed to continuous improvement.

Standards and guidelines

WCAG 2.1 Level AA

We target conformance with the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA — the internationally recognized standard for web accessibility.

Keyboard navigation

All functionality is operable via keyboard alone. Tab order follows a logical reading sequence. Dropdown menus and modals trap focus appropriately.

Screen reader support

The site is tested with common screen readers. ARIA roles, labels, and live regions are used to communicate dynamic content changes.

Color & contrast

Text and interactive elements meet minimum contrast ratios. Color is never used as the sole means of conveying information.

Accessibility features on this site

The following accessibility features are implemented across the Shine Pro website:

  • Skip-to-content link available at the top of every page for keyboard users
  • All interactive elements are keyboard-navigable using Tab, Enter, and Space
  • Visible focus indicators on all buttons, links, and form fields
  • Semantic HTML landmarks: <header>, <main>, <nav>, <footer>, <section>
  • All navigation menus include aria-label, aria-expanded, and aria-controls attributes
  • Images include descriptive alt text; decorative images use empty alt=""
  • Color contrast ratios meet WCAG 2.1 AA standards (4.5:1 for normal text, 3:1 for large text)
  • Form fields are associated with visible labels
  • Error messages are announced to screen readers via ARIA live regions
  • Page titles are unique and descriptive on every route
  • Language attribute set to English (lang="en") on the HTML element
  • No content flashes or auto-playing audio without user control

Known limitations

While we strive for full WCAG 2.1 AA conformance, some areas of the site may not yet fully meet all guidelines:

  • Third-party embedded content (such as maps and payment forms) may have accessibility limitations outside our direct control.
  • Some older blog posts may contain images without descriptive alt text — we are working to update these.
  • Video content may not yet have full captions or audio descriptions.

Compatible assistive technologies

This website is designed to be compatible with the following assistive technologies:

Screen readers

NVDA, JAWS, VoiceOver, TalkBack

Keyboard navigation

Full keyboard access without a mouse

Browser zoom

Up to 200% without loss of content or function
